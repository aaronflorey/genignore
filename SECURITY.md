# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in `genignore`, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email the maintainer directly. Include as much of the following as possible:

- A description of the vulnerability and its impact
- Steps to reproduce the issue
- Affected versions, if known
- Any suggested mitigations

You should receive an initial response within 72 hours.

## Scope

This policy applies to the `genignore` source code in this repository, including the CLI binary, embedded template catalogs, and provider detection logic. It does not apply to the upstream `github/gitignore` template content (which is licensed and maintained separately by its respective authors).

## Supported versions

Only the latest release of `genignore` is actively supported with security updates.
